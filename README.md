# Customer Churn Analysis | Power BI

## About the Project
This project analyzes customer churn in the telecommunications industry to understand customer attrition patterns and identify opportunities to improve customer retention. An interactive Power BI dashboard presents key metrics and business insights to support data-driven decision-making.

## Business Problem
Customer churn affects business growth and recurring revenue. The goal of this project is to explore churn patterns across contract types, customer tenure, monthly charges, and service categories to better understand customer behavior.

## Tech Stack
- **Power BI** — Dashboard development and visualization
- **Power Query** — Data preparation and transformation
- **DAX** — Measures and KPI calculations

## Dataset
Telecommunications customer churn dataset.

[View Dataset on Google Drive](https://drive.google.com/file/d/12cb64WyOt9zE6tFyz8Gp0uxCO3Jk1UiY/view)

## Dashboard Features
- Total customers, churn rate, and retention rate KPIs
- Churn analysis by contract type
- Churn rate by customer tenure band
- Monthly charge comparisons by customer type and churn status
- Service analysis by online security and backup categories
- Retained customers by risk category

## Key Insights
- **7,043** total customers
- **26.54%** overall churn rate
- **73.46%** customer retention rate
- Month-to-month contracts have the highest number of churned customers.
- Churn rate is highest among customers with 0–6 months of tenure.
